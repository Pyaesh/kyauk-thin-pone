summary: ကျောက်သင်ပုန်းတွင် ပထမဆုံး 3D ပုံ စဆွဲရန်။
---

ကျောက်သင်ပုန်းသည် Layerling ကို အခြေခံထားသော 3DPMM ၏ browser CAD ဖြစ်သည်။ အကောင့်ဖွင့်စရာမလိုဘဲ ပုံဆွဲနိုင်သည်။

## ပုံအသစ် ဆွဲရန်

{{ui:dashboard.createDesign}} ကို နှိပ်ပါ။ ပုံသဏ္ဌာန်တစ်ခုကို သင်ပုန်းပေါ် ဆွဲချပြီး အရွယ်အစား၊ တည်နေရာနှင့် လှည့်ထောင့်တို့ကို ပြင်နိုင်သည်။

{{ui:dashboard.importGeometry}} ဖြင့် `.lyl`, STL, OBJ, 3MF, STEP နှင့် SVG ဖိုင်များကို ဖွင့်နိုင်သည်။

## သိမ်းဆည်းရန်

ဒီဇိုင်းများကို ဤ browser ၏ storage ထဲမှာ အလိုအလျောက် သိမ်းပေးသည်။ တခြားစက်တွင် အလိုအလျောက် မပေါ်ပါ။ Browser data မဖျက်မီ {{ui:dashboard.backupAll}} ဖြင့် အရန်သိမ်းပါ။ ဖိုင်ထုတ်ပြီးလည်း သိမ်းနိုင်သည်။

## ကိရိယာများ

အပေါ်ရှိ icon များကို ညွှန်ကြည့်လျှင် ကိရိယာအမည်ကို ပြပေးသည်။ ဘယ်ဘက်မှ မြင်ကွင်းရွေးနိုင်ပြီး ညာဘက်မှ ပုံသဏ္ဌာန်နှင့် အရွယ်အစားကို ရွေးနိုင်သည်။ ဆက်တင်များတွင် printer နှင့် သင်ပုန်းအရွယ်အစားတို့ကို ပြောင်းနိုင်သည်။

မပြန်ရသေးသော လမ်းညွှန်အခန်းများကို အင်္ဂလိပ်လို ပြထားမည်။
